# 可视化工作台统一改造方案

> 状态：执行中（P0、P1、区划编辑、POI 介绍、运营消息与公共交通导视已完成；下一目标：路牌 / 物料）
> 目的：把后台各可视化工作台统一成接近 Figma 的编辑体验，并让新增工作台有固定接入路径。

## 1. 设计原则

1. **工具只有一处入口**：桌面端与移动端都放在画布顶部居中的浮动胶囊。左侧不再放工具栏。
2. **左图层、右属性**：左侧只放页面/图层/元素树，右侧只放属性检查器。画布始终铺满工作区，面板浮在画布上。
3. **业务与内核分离**：内核不 import 任何业务模块；业务只通过 props、回调与编辑器事件接入。
4. **一套快捷键语义**：工具键、编辑键、视图键全局一致，业务键允许覆盖但必须登记。
5. **移动端不是缩小版**：工具栏保持在顶部，图层与属性合并为工具栏下方的抽屉，状态栏隐藏，触控目标不小于 44px。

## 2. 目标布局

| 区域 | 桌面端                                                                            | 移动端（≤760px）                 |
| ---- | --------------------------------------------------------------------------------- | -------------------------------- |
| 顶部 | 页面顶栏：返回 / 标题 / 状态 / 保存，所有二级页面标题栏吸顶（sticky）不随内容滚动 | 同左，压缩                       |
| 工具 | 画布顶部居中浮动横向胶囊                                                          | 同一位置，尺寸放大到 44px        |
| 左侧 | 图层 / 元素树（浮动面板，可与属性一起整体隐藏）                                   | 页面底部的抽屉，与属性二选一     |
| 中间 | 画布铺满，缩放条在右下                                                            | 画布全宽，缩放条在右下           |
| 右侧 | 属性检查器（浮动面板）                                                            | 复用同一个底部抽屉，通过层级切换 |
| 底部 | 不单独设状态条：工具、几何类型、选中项都写在两块面板的标题栏里                    | 隐藏                             |

侧边面板只有两种状态：**展开** 与 **完全隐藏**。不再保留 44px 的折叠标题条。

### 断点行为

| 宽度       | 侧栏形态                                                                                                                                                                                         |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ≥1280px    | 左图层、右属性，两列独立浮动                                                                                                                                                                     |
| 761–1279px | 图层与属性共用左侧一列，靠层级二选一：未选中对象时显示图层；选中对象后属性覆盖图层，属性头部「返回图层」可退回                                                                                   |
| ≤760px     | 工具栏在顶部；图层面板与属性检查器是页面底部的抽屉，同一时间只展示其一，属性页提供「返回图层」。开启侧边操作栏时，浮动工具栏、返回、保存整体搬进侧栏，页面标题栏只保留标题，面板自动避让侧栏宽度 |

宽度不足时不再强行挤出两列，属性面板与图层面板共列、必要时靠层级覆盖，这是默认策略。

| 视图     | 滚轮缩放、`Shift+滚轮` 横移、按住 `Space` 临时手型、鼠标中键拖拽临时手型、触屏双指捏合缩放 / 两指平移、`Ctrl+0` 适配 | 临时手型不改变当前工具，松开/抬起即恢复；触屏单指始终跟随当前工具，视口操作交给双指 |

### POI 几何当前形态

- 图层树：`几何 → 边界 / 环 / 矩形 → 控制点`。分组行提供「添加减去图形 / 添加多边形 / 添加矩形」等结构操作。
- 填充规则：多边形一律按「所有外边界减去所有减去图形」渲染，使用 evenodd 复合路径，图层树里的减去图形会在地图上真正挖空。
- 行内操作：图层树的每个分组行和控制点行在悬停或选中时都会浮出「在此后插入 / 创建副本 / 上移 / 下移 / 移除」图标按钮，直接作用于该行，不要求先选中；快捷键为 `Ctrl+D`、`Ctrl+[`、`Ctrl+]`、`Delete`。
- 面板开关：工具栏左侧按钮在「全部面板展开 / 全部面板隐藏」之间切换，不再只控制图层树。
- 工具栏：与线路走向、班次运行图共用同一套胶囊与紧凑收折规则；紧凑模式只保留「面板 + 工具 + 更多」三个胶囊，插入模式与其余非工具组统一收进同一个菜单。
- 工具图标：全部使用 Material Symbols；选择工具用 `near_me`，改完图标后运行 `pnpm icons:material-symbols:sync` 同步字体子集。
- 单击与双击：画布和图层树都支持单击选定、双击把焦点送进属性检查器的第一个字段（移动端会顺势展开属性抽屉）。
- 矩形：不再使用 4 个边界字段，而是拆成 4 个顶点。编辑顶点 X 会更新对应的 `minX` 或 `maxX` 边，编辑 Z 会更新对应的 `minZ` 或 `maxZ` 边，等价于同步修改相邻两条边。
- 状态信息：由两块面板标题栏承载，不再单独渲染底部状态条，也不再在标题栏右侧显示 `visual-editor-page-status` 文案。
- 全局属性：放在右侧属性检查器里。未选中任何对象时，检查器标题变为「全局属性」，展示 POI 形式、几何类型、控制点数量与包围盒尺寸；选中对象后同一块面板切换为对象属性。这样与 Figma「右侧永远是属性面板」的模型一致，也不需要把全局设置塞到图层树上方。≤1279 通过图层面板标题栏的共享「全局属性」入口打开。

### POI 介绍当前形态

- 入口与外壳：`/admin/map-poi/intro-editor?markerId=...` 继续复用 `VisualEditorShell`（workspace），`Ctrl+S` 保存并停留、`Ctrl+Enter` 保存并返回；保存仍走 `AdminPoiPanel.save()` 的字段归一化与草稿逻辑，脏状态下拦截站内链接与关闭页。
- 布局：中间是按公开端 `map-poi-detail-panel` 结构与 class 复刻的只读预览；左侧结构树与右侧属性检查器复用 `.poi-visual-layer-panel` / `.poi-visual-inspector` 浮层，≥1280 左右两列，761–1279 共用左列按选中态二选一，≤760 为底部抽屉。
- 图层树：固定为「标题栏 → 图片 → 简介 → 更多信息 → 设施 → 地点关系 → 链接」七个章节，下面展开字段。标题栏含名称 / 分类 / 图标；图片按 `图片 1..N` 列出并支持行内上移 / 下移 / 移除；更多信息含营业时间 / 地址 / 楼层 / 地址道路；设施按 `设施 1..N` 列出；地点关系含父地点与只读子地点列表；「建造者信息」先保留禁用占位行，等待后续 PR 接入。结构操作固定在面板底部（添加图片、添加设施）。
- 属性检查器：未选中显示全局属性（名称、分类、简介字数、图片数量、设施数量、子地点数量、营业 / 地址填写状态与完成度）；选中章节显示整组表单，选中字段只显示单字段控件。标题栏章节允许直接修改名称、分类与展示图标（复用 `AdminPoiIconPicker`，含「跟随分类默认 / 不使用图标」）。
- 预览：按 `/map` 公开详情卡做内容级复刻，使用同一套 `map-poi-detail-*` 结构，分「简介 / 设施·出入口」两个页签。简介页含图片集（上一张 / 下一张 / 计数）、简介、地址 / 楼层 / 营业时间 / 所属地点、子地点分组与「编辑链接」按钮；设施页含设施列表与按分类分组的子地点列表。链接按钮不跳转，点击后选中链接字段进入右侧检查器；其他可编辑区域点击后同样选中对应章节 / 字段。坐标、类型、绑定区域、运营消息与底部操作栏属于地图交互，不在预览里复刻。
- 图片编辑：`AdminPoiImageEditor` 改用标准 `material-field`、`secondary-action-button`、`icon-action-button` 与标准文件输入写法，不再使用裸输入框和裸按钮。
- 设施：独立章节，章节检查器复用 `PoiFacilityEditor`，选中单条设施时复用抽出的 `PoiFacilityRow`；保存时沿用原有设施描述非空校验。
- 地点关系：父地点复用 `ParentMarkerSelect` 绑定；子地点从当前标记的 `parentMarkerId` 反查为只读列表，点击可进入对应地点的简介工作台；新增子地点仍回 POI 主列表。
- 预览宽度：工具栏「预览视图」组提供 240 / 340 / 760 三档宽度切换，分别对应移动端最窄、桌面端与移动端最宽；预览超出可用宽度时由画布横向滚动承接。工具栏不新增内容工具组，所有内容编辑都从章节 / 字段进入。
- 快捷键：登记为 `POI_INTRO_SHORTCUT_IDS`（保存 / 保存并返回），帮助面板按 `/admin/map-poi/intro-editor` 单独成节；没有新增几何或视图键位。

### 运营消息当前形态

- 入口与外壳：`/admin/operations/editor?contentId=...` 继续复用 `VisualEditorShell`（workspace），`Ctrl+S` 保存并停留、`Ctrl+Enter` 保存并返回；保存仍走 `PUT /api/admin/operations/contents/:contentId`，payload 保留 `assetIds / scheduledAt / metadata` 全量字段。旧内容在进入时提示先接管，已归档内容禁止保存并提示先在列表恢复为草稿；脏状态下拦截站内链接与关闭页。
- 布局：中间是真实 `MarkdownBlocks` 预览；左侧「文档结构」只有一棵树，不再提供「块 / 大纲」切换；右侧属性检查器未选中时显示全局属性与关联内容入口，选中文档头或块后显示对应属性。≥1280 左右两列，761–1279 共用左列并按选中态二选一，≤760 为底部单抽屉。
- 工具栏：只有一处 `EditorToolbar`，最左侧是面板总开关；宽屏提供「预览 / 分栏 / 源码」三个图标切换，移动端改为「预览 / 源码」分段切换；另有 240 / 340 / 760 三档预览宽度按钮。分栏固定 50/50，不做拖拽比例；窄屏禁用分栏并自动回到预览。

## 7. 接入检查清单

新增或改造一个工作台时逐项确认：

1. 工具是否只有一处入口，且使用 `EditorToolbar`。
2. 左侧是否只放图层/元素树，右侧是否只放属性。
3. 面板是否只有「展开 / 完全隐藏」两态，且由工具栏按钮控制。
4. 快捷键是否登记进 `EDITOR_SHORTCUT_CATALOG`，帮助面板可见。
5. 保存语义是否为 `Ctrl+S` 留在当前页、`Ctrl+Enter` 保存并返回。
6. 是否有未保存离开确认（路由切换 + `beforeunload`）。
7. 移动端：工具落底、属性抽屉、触控目标 ≥44px。
8. 运行 `pnpm --filter @yct/web typecheck`。
9. 运行 `pnpm ui:controls:sync`，再运行 `pnpm ui:controls:check`。
10. 在 `/dev/controls` 确认新增共享控件的展示与真实业务一致。

## 8. 已知风险

- `map-stage.tsx` 是前台地图，不是编辑器内核，不做改造，只做适配。
- 快照式历史在班次/线路的大数组上需要结构共享与上限，否则连续拖拽会卡。
- React 19 StrictMode 下 window 级快捷键必须走统一注册表，避免重复挂载。
- 新组件会进入 `ui-controls` 清单，构建前必须同步，否则 `build` 失败。
